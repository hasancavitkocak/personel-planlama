# Workforce Scheduling - Personel Planlama Sistemi

Modern, Apple tarzı premium tasarıma sahip bakım iş gücü planlama ve atama sistemi.

## 🚀 Özellikler

- ✨ **Premium Glassmorphism Tasarım** - Apple tarzı modern arayüz
- 🎯 **Drag & Drop** - Sürükle-bırak ile kolay iş emri atama
- ⚠️ **Çakışma Tespiti** - Otomatik çakışma kontrolü ve uyarılar
- 📊 **Gerçek Zamanlı İstatistikler** - Anlık veri görüntüleme
- ✅ **Tam CRUD İşlemleri** - Create, Read, Update, Delete
- 🎨 **Smooth Animasyonlar** - Framer Motion ile akıcı geçişler
- 📅 **Planning Calendar** - Outlook benzeri takvim görünümü
- 🔧 **Mock Data** - Prototip için hazır test verileri

## 🛠️ Teknolojiler

- **React 19** - Modern UI framework
- **TypeScript** - Type-safe development
- **Vite** - Hızlı build tool
- **Framer Motion** - Animasyonlar
- **Lucide React** - Modern iconlar
- **date-fns** - Tarih işlemleri

## 📝 Kullanım

1. Sol sidebar'dan atanmamış iş emirlerini görüntüleyin
2. İş emrini sürükleyip personel satırına bırakın
3. Sistem otomatik olarak çakışmaları kontrol eder
4. "Yeni İş Emri" butonu ile yeni iş emri oluşturun
5. Tarih navigasyonu ile farklı günleri görüntüleyin
